## Featured project — Kasi-Till

**An Android point-of-sale app and web owner portal for South African spaza shops.**

Kasi-Till helps shop owners record sales, manage stock and view reports from a phone. Sales can be recorded offline and synchronised when the connection returns, so unreliable internet does not stop the shop from keeping records.

I built the backend with **Java, Spring Boot and PostgreSQL**, used **Flyway** for database migrations, and deployed it with **Docker on AWS**. The work includes REST APIs, staff authentication, reporting and retry-safe sales uploads. Debugging synchronisation and licence revalidation taught me to trace problems through the app, API and database.
